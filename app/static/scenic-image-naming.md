# 景区图片放置与命名规范

## 放置路径
- 目录：`/app/static/poster/`

## 固定命名（必须完全一致）
1. `hongyadong.jpg` 对应 洪崖洞
2. `ciqikou.jpg` 对应 磁器口古镇
3. `wulong.jpg` 对应 武隆天生三桥
4. `changjiangsuodao.jpg` 对应 长江索道

## 建议规格
- 格式：JPG（推荐）
- 比例：16:9（建议 1280x720 或 1920x1080）
- 单图大小：建议小于 500KB（移动端加载更快）

## 替换说明
- 你只需要把照片按上述文件名放入 `/app/static/poster/`，页面会自动使用。
- 已不再使用 SVG 方案，代码已全部切换为 JPG 引用。
